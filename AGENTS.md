# StudySinc — правила для AI-агентов

## Дизайн-контракт

Перед любой UI-правкой прочитай `DESIGN.md` в корне репозитория — это
обязательный контракт дизайн-системы («Тихий инструмент с характером»).

Жёсткие правила:

- Цвета, радиусы, тени, шрифты — только через токены из `app/globals.css`
  (`@theme`). Произвольные hex/oklch-значения и хардкод цветов Tailwind
  (`blue-600`, `gray-900` и т.п.) в компонентах запрещены — это баг.
- Соблюдай секцию Don'ts из `DESIGN.md`: никаких градиентов, glassmorphism,
  hover-lift карточек, многослойных теней, скруглений > 12px, эмодзи в UI,
  стерильных серых нейтралей.
- Числа геймификации и дедлайнов (XP, streak, позиции рейтинга, даты) —
  только через `.font-num` (JetBrains Mono + tabular-nums).
- Один акцент (янтарь) питает всю геймификацию; success/danger — только
  статусы задач. Радуга акцентов запрещена.
- Тёмная тема (`.dark`) — первоклассный гражданин: любой новый компонент
  проверяется в обеих темах.

## Стек

Next.js 16 + React 19, Tailwind CSS 4 (тема в `app/globals.css` через
`@theme`, без tailwind.config), shadcn/ui (Radix), Supabase, next-themes
(`attribute="class"`). Сборка: `npm run build`; dev: `npm run dev`
(требуется `.env.local` с ключами Supabase).
